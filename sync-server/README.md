# 観戦用 中継サーバー（インターネット公開）

参加者・HP訪問者が **インターネット越しに誰でも** 大会データをリアルタイム観戦
できるようにするための、小さな WebSocket 中継サーバーです。

アプリ本体は GitHub Pages（静的配信）で動くため、常時起動が必要なこの中継
サーバーだけは外部ホストに置きます。**一度立てれば以降は設定不要**で、観戦用
URL を HP に貼るだけになります。

---

## 仕組み

```
   運営端末(スコア入力)                 観戦者(スマホ/PC)
        │  wss://                          │  wss://
        ▼                                  ▼
   ┌──────────────────────────────────────────┐
   │   中継サーバー（Render等）                 │
   │   ・最新スナップショットをルーム毎に保持    │
   │   ・観戦端末の接続時に即配信                │
   └──────────────────────────────────────────┘
```

運営端末が離線していても、サーバーが保持した直近データを観戦端末へ配信するため
「読み込めません」になりません。

---

## デプロイ手順（Render・無料・推奨）

1. [Render](https://dashboard.render.com/) にGitHubでログイン
2. **New → Blueprint** を選び、このリポジトリを指定
   （リポジトリ直下の `render.yaml` が自動検出されます）
3. **Apply** でデプロイ。数分で `https://<name>.onrender.com` が発行されます
4. 観戦で使うのは **`wss://<name>.onrender.com`**（`https` を `wss` に置換）
5. そのURLを **GitHubリポジトリ → Settings → Secrets and variables → Actions →
   Variables** に `SYNC_SERVER_URL` として登録
   - 任意で `PUBLIC_ROOM`（例: `TCTA01`）も登録すると、HP掲載用URLが
     クエリ無しの固定URLになります
6. `main` へ push（または Actions を手動実行）すると、値がビルドに埋め込まれ、
   全端末が個別設定なしで公開・観戦できるようになります

> ⚠️ Render 無料プランは15分アクセスが無いとスリープし、次アクセスで自動復帰
> します（初回のみ数十秒）。大会中は稼働し続けるため実害は小さいです。常時
> 即応が必要なら Render の有料プラン、または Railway / Fly.io をご利用ください。

### 別ホストを使う場合

`sync-server/Dockerfile` を同梱しています。Railway / Fly.io / 自前VPS など Docker
が使えるホストならそのままデプロイできます。多くのホストは `PORT` を環境変数で
注入し、サーバーはそれに従います。TLS（`wss://`）で公開できることが条件です。

---

## ローカルで動かす（LAN内テスト用）

```bash
cd sync-server
npm install
npm start          # = node server.mjs 。既定ポート 8787
```

同一LAN内なら `ws://<このPCのIP>:8787` で接続できます（インターネット公開には
上記のホスティングが必要です）。

---

## 環境変数

| 変数 | 用途 | 必須 |
|------|------|------|
| `PORT` | 待ち受けポート（ホストが自動注入） | 任意 |
| `GEMINI_API_KEY` | Gemini TTS プロキシを使う場合のみ | 任意 |
